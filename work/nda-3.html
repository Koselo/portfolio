NDA Project 03

UI Design · Design System

Role

UI Designer

Year

2026

Type

UI Design · Design System

Challenge

The client — a confidential e-commerce brand — had accumulated significant design debt. The Figma workspace had grown without structure: inconsistent components, duplicated styles, and screens that had diverged from each other over time.

There was no shared design system to speak of. The team needed a solid foundation before any meaningful product work could move forward.

What I Delivered

01

Design System from Scratch

Built a new design system tailored to the e-commerce context — tokens, components, patterns — giving the team a single source of truth to design and build from.

02

Figma Cleanup

Restructured the entire Figma workspace — removed redundancy, aligned naming conventions, and organised existing designs so they could actually be used and maintained.

03

Pixel-Perfect UI Screens

Designed key product screens with precise visual execution — consistent with the new system, handoff-ready, and built to the standard the product deserved.

Impact

  • A clean, scalable design system where there was none before.
  • A Figma workspace the team can actually navigate and use.
  • UI screens that reflect the quality the brand wants to project.
